307102 — Statistics for Business

R track | University of Petra

This is a complete R version of 307102. It teaches the same statistics in the same order as the Excel materials, but the tool is R instead of Excel. Nothing in the original course folders has been changed — you may use either track, or both.

TipNew to R? Start here

Work through the three sections in order. Each one assumes the R introduced in the previous ones.

  1. Read the install guide and set up R — about 10 minutes locally, or 30 seconds on Posit Cloud.
  2. Open 307102-R-Track.Rproj in RStudio. This sets the working directory correctly and is the most common fix for “file not found” errors.
  3. Run 1-Intro-to-R-Language/setup.R once. It installs the packages, copies the datasets into data/, and checks that everything loads.

The dataset

Almost every example uses one dataset: supermarket_sales.xlsx — 1,000 transactions from a supermarket chain operating three branches.

This is deliberate. Learning statistics and learning R at the same time is already two things; adding a new business context every week would make it three. Staying with one dataset builds genuine familiarity, which means you can tell when a result looks wrong — the single most important skill in applied statistics.

How R is taught

You are not asked to learn R as a programming language. You are taught the smallest set of tools needed to do statistics, introduced when each becomes necessary.

Section 1 covers eight concepts and no more — data frames, $, reading a file, the pipe |>, and the five dplyr verbs. No loops, no writing functions.

Every notebook opens with a “New R this week” table listing the new functions it introduces, never more than five or six. Read cumulatively, these become the course’s R reference.

The scaffolding decays. Section 2 has you filling blanks like mean(sales$______). By section 3.4 you get a business question and write everything yourself. The support is removed slowly enough that you should not notice it going.

A note on results

ImportantMost tests in section 3 come back non-significant

That is deliberate, and it is the most valuable feature of this dataset.

Students arrive expecting statistics to produce findings. What it mostly produces is the disciplined conclusion that an apparent pattern is indistinguishable from noise. A course where every test is significant teaches you to expect significance — and you then go and find it whether it is there or not.

If a test comes back null, you have almost certainly done it right.

What this track adds beyond the Excel course

Things R makes easy and Excel makes painful:

  • Simulation and bootstrap. The Central Limit Theorem is demonstrated by simulating it. Confidence intervals are derived by resampling before the formula appears, so you see what the formula approximates.
  • Assumption checking. Q-Q plots, Shapiro–Wilk, Levene’s test and full residual diagnostics.
  • Effect sizes. Cohen’s d and eta-squared alongside every p-value, with a live demonstration that any difference becomes significant at a large enough sample.
  • Self-check questions with collapsible answers throughout.

Excel has no built-in effect size, no Levene’s test, no Shapiro–Wilk and no post-hoc correction. That gap is the clearest argument for teaching this material in R.
